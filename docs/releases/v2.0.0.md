# CodeChat 2.0.0

CodeChat 2.0 turns the project into a reliable local AI coding workspace: editor-aware conversations, smooth streaming, local model discovery, persistent history, safer defaults, and a tested first-run experience.

## Highlights

- **Discuss current code naturally.** Relevant questions include the current editor source on the first turn, make that attachment visible, and preserve it for follow-ups.
- **Choose the right interaction.** Use Code Teacher, Code Reviewer, or Code Generator with JavaScript, TypeScript, Python, HTML, and CSS starter code.
- **Use models that are really available.** The selector is populated from the local Ollama installation, with refresh and stale-selection recovery.
- **Read stable streamed answers.** Responses render smoothly, follow only near the bottom, and provide clear generating, stopped, completed, and failed states.
- **Resume local conversations.** PostgreSQL-backed History refreshes immediately, reloads complete context, and confirms permanent deletion.
- **Start from a clean machine confidently.** Guided setup creates local configuration, initializes the schema, checks Ollama, and reports actionable recovery steps.

## Reliability and security

- The backend binds to `127.0.0.1` by default.
- Browser origins are matched exactly against the trusted local list.
- Requested models are validated against the current installed inventory.
- Heavy editor and Markdown dependencies are loaded only when needed.
- The release candidate passed a clean `npm ci`, 80 automated tests, type checks, production builds, built-service smoke testing, browser verification, and an audit with zero known vulnerabilities.

## Install

CodeChat 2.0 is published as a source release and runs locally with Node.js 20+, PostgreSQL, and Ollama.

```bash
git clone --branch v2.0.0 https://github.com/jimmyli-520/codechat.git
cd codechat
npm install
npm run setup
```

Add your local PostgreSQL credentials to the generated `server/.env`, run `npm run setup` again, install an Ollama chat model if needed, and start CodeChat:

```bash
ollama pull llama3.2:3b
npm run dev
```

Open `http://localhost:5173`.

See the [complete quick start](https://github.com/jimmyli-520/codechat/blob/v2.0.0/README.md#quick-start), [architecture and limitations](https://github.com/jimmyli-520/codechat/blob/v2.0.0/docs/ARCHITECTURE.md), and [release-candidate QA](https://github.com/jimmyli-520/codechat/blob/v2.0.0/docs/RELEASE_CANDIDATE_QA.md).

## Known limitations

CodeChat 2.0 is a trusted, local, single-user application. It does not yet open project folders, execute code, budget long conversation context, provide versioned database migrations, package a desktop binary, or run browser end-to-end tests in CI. Monaco may retrieve its runtime assets from its configured CDN on first editor use.
